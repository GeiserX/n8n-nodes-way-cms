# CLAUDE.md — n8n-nodes-way-cms

## Overview
n8n community node for Way-CMS, enabling management of archived web content, file operations, search-and-replace, backup workflows, and project switching within n8n workflows.

## Tech Stack
- TypeScript
- n8n community node SDK
- Vitest (test framework)
- Node.js (build via `package.json` scripts)

## Development
```bash
npm install
npm run build        # Compile TypeScript
npm run lint         # Lint source
npm test             # Run vitest suite

# Icon generation
node build-icons.cjs
```

## Architecture
- `nodes/` — Node implementations (File CRUD, Search/Replace, Backup, Project resources)
- `credentials/` — Way-CMS credential definition (URL + Bearer auth token)
- `tests/` — Vitest test suite
- `docs/` — Documentation and images

## Key Rules
- Never hardcode auth tokens; use n8n credential system with Bearer token
- Follow n8n community node conventions for resource/operation patterns
- Search-and-replace supports preview mode before applying changes
- Package published to npm as `n8n-nodes-way-cms`
